# 使用指南

安装依赖与基础启动命令见 [项目首页](../README.md#快速开始)。以下以两个本地测试账号为例。

## 创建账号并连接

1. 启动服务端，再打开两个桌面客户端。
2. 两个客户端均填写 `http://127.0.0.1:8000`。
3. 分别注册 `alice` 和 `bob`，设置各自密码。私钥在本地生成，并加密保存在各自账号目录中。
4. 后续登录必须使用原账号对应的本地密钥库和密码。

如果修改服务端监听端口，例如使用 `--port 8010`，需要同时将客户端地址改为 `http://127.0.0.1:8010`。

## 添加好友与收发消息

1. Alice 输入 `bob`，点击“添加/查询好友”；Bob 同样查询 `alice`。
2. 双方按需点击“接受好友”，建立好友关系。
3. 选择好友，在输入区编写文本并发送。
4. 在线客户端通过 WebSocket 接收事件并在本地验签、解密；离线后重新登录，可使用“刷新离线消息”拉取待收消息。

右侧面板展示公钥指纹、会话状态和文件记录。当前 `trusted` 标签由程序设置，不代表独立的身份核验；参见 [安全说明](SECURITY.md)。

## 发送和接收文件

1. 选择好友，点击“发送安全文件”。
2. 选择普通文件。基础扫描通过后，客户端加密并上传文件包。
3. 接收方在右侧文件记录中选择文件，点击“下载选中文件”。
4. 客户端验证签名与哈希、解密并复检，成功后将文件保存到账号的 `downloads/` 目录。

默认扫描大小上限为 50 MiB，`.exe`、`.bat`、`.ps1` 等扩展名会被阻断。扫描通过仅表示通过当前基础规则。

## 常见问题

- **提示缺少模块**：确认当前终端已激活项目虚拟环境，再执行 `python -m pip install -r requirements.txt`。
- **桌面窗口未打开**：确认已安装 PySide6，并在有图形桌面的环境中启动；无图形环境可运行 `python -m client.demo`。
- **注册或登录失败**：核对服务端地址、账号与密码，确认本地 `key_store.json` 仍存在；服务端重启后需重新登录。
- **收不到实时消息**：确认双方连接同一服务端且已查询对方公钥，查看实时连接状态，或尝试刷新离线消息。
- **文件被阻断**：检查文件大小、扩展名和规则命中信息。不要通过修改扩展名绕过扫描。
- **EICAR 演示或测试无法读取文件**：检查终端防护的隔离记录。系统可能在程序读取前就隔离测试文件，因此无法据此得出应用扫描通过或失败的结论。

## 运行数据管理

客户端账号目录包含私钥库、聊天数据库和下载文件；服务端数据库保存账号与密文中继状态。备份和重置前先停止相关进程，并明确区分这两类数据。

删除本地私钥库后无法仅凭密码恢复密钥。原账号仍保留在服务端时，重新创建同名本地密钥库不能替代原私钥。
